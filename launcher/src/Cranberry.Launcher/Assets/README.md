# Launcher artwork and type

`kotk-keyart.jpg` is the existing crown/sunset King of the Kill promotional artwork,
downloaded unchanged from https://getwallpapers.com/wallpaper/full/2/3/2/986145-h1z1-king-of-the-kill-wallpapers-1920x1080-for-iphone-5s.jpg.
The artwork and game marks belong to their respective owners. This is a community
launcher; its application name and connection identity remain Cranberry.

`Oswald-Regular.ttf` and `launcher.ico` were copied from the local August client,
from `UI/Resource/Fonts/Oswald-Regular_0.ttf` and `LaunchPad.ico` respectively.
Oswald is licensed under the SIL Open Font License; see `Oswald-OFL.txt`.

Layout reference: Noah Watkins' original SOE LaunchPad portfolio,
https://www.noahwatkins.com/game-launcher-ui. This establishes the compact frame,
artwork and bottom launch bar, rather than an exact 2017 screenshot reconstruction.

All assets are embedded so the standalone launcher and setup work without loose files
or network access for presentation.
