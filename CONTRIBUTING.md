# Contributing

Bug reports, ideas and fixes are all welcome.

## Bugs and ideas

[Open an issue](https://github.com/Mixcria/h1z1-pre-season-5-project/issues/new). For bugs, include:

- What you did, what happened and what you expected.
- Your project release and Windows version.
- A screenshot or short clip, if it helps.

Remove passwords, keys and private account details from anything you share.

## Code changes

1. Fork the repo and create a branch for your change.
2. Follow the [build instructions](README.md#build), run the tests and try your change in game where relevant.
3. Open a pull request against `main`. Explain what changed and what you tested.

Keep fixes focused, preserve existing credits, and protect players' accounts and saves. For bigger changes, open an issue first so we can talk it through.
